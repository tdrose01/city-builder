# Tech Stack - City Slacker

## Web Frontend
- **React 19 (Vite):** Core library for building the game's UI and managing state.
- **Tailwind CSS 4:** Utility-first CSS framework for rapid UI development and styling.
- **Three.js (React Three Fiber):** 3D engine used for rendering the board, dice, and environment.
- **Framer Motion:** Animation library for smooth UI transitions and cinematic feedback.

## Backend & Database
- **Supabase:** Used for real-time data sync and authentication (if applicable).
- **Firestore (NoSQL):** Primary database for storing player progress, sticker collections, and city states.

## Infrastructure & Automation
- **Modal (Python):** Serverless platform for running economy simulations and development automations.
