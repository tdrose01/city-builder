# Initial Concept

Urban-themed, Monopoly-Go-style board loop with dice-based progression, City Funds, and landmark upgrades. The current web prototype focuses on the board loop, dice economy, and tile rewards.

## Recent Updates (2026-01-20)

### Board Redesign
The board has been completely redesigned with a **20-tile layout** (5 per side) featuring uniform sizing, better spacing, and simplified labels for optimal readability and user experience.

### New Features
- **Autoroll System**: Toggle button for continuous automatic dice rolling with smart pausing on upgradeable landmarks
- **Event Prestige System**: Reset milestone progress for enhanced rewards (up to 3.0x multiplier)
- **Mission Improvements**: Completion rewards ($10k + 25 dice + 2 packs) and infinite reset cycles
- **Landmark Visibility**: Always-visible level progression (e.g., "3/5") with color-coding

# Product Definition - City Slacker

## Product Vision
City Slacker is an urban-themed, Monopoly-Go-style board loop designed for fans of board-loop games who enjoy progression and collection. The game focuses on a rewarding "roll -> move -> upgrade" cycle set in a vibrant "Neon Harbor" environment.

## Target Audience
- Fans of board-loop games (like Monopoly Go) who enjoy visible progression and collection mechanics.

## Core Objectives
- Finalize the core board loop mechanics and "feel," ensuring every action feels impactful and rewarding.
- Prioritize high-fidelity feedback, including cinematic dice rolls, celebratory landmark level-ups, and dynamic token movement.

## Key Features
- **Polished Board Loop:** High-quality cinematic dice animations, screen shake, and particle effects for tile landing on a clean 20-tile board.
- **Optimized Board Design:** Uniform 6x6 grid with 5 tiles per side, larger tile sizes (110px), and better spacing (12-20px gaps) for improved readability.
- **Simplified Visual Hierarchy:** Clean tile labels showing only type names (FUNDS, HEIST, SHIELD, etc.) for instant recognition.
- **Autoroll System:** Continuous automatic rolling with smart pausing on upgradeable landmarks, reducing repetitive clicking.
- **Event Prestige System:** Infinite replayability through milestone resets with reward scaling (1.5x per prestige, capped at 3.0x).
- **Mission Cycles:** Complete missions for substantial rewards, then reset for infinite replayability with cycle tracking.
- **Clear Landmark Progression:** Always-visible level display (e.g., "3/5") with color-coding and MAX badges.
- **Urban Progression:** Celebrate landmark upgrades with distinct celebratory visuals and real-time payout counters.
- **Dynamic Board Content:** Interactive corner tiles paired with smooth token transitions and hop animations.
- **Compact Status Display:** Board status integrated into center area, eliminating separate HUD bar for cleaner layout.
- **Sticker Meta-Progression:** Completing sticker sets provides significant currency rewards (Dice and Funds) to accelerate gameplay.
- **City Evolution:** Completing one city unlocks new, uniquely themed boards with varied layouts.

## Visual Identity
- **Neon Harbor Aesthetic:** A high-contrast nighttime palette with glowing lights and glass surfaces.
- **Modular Architecture:** A mix of classic brick landmarks and modern steel structures.
- **Evolving Backdrop:** The city backdrop dynamically evolves and lights up as the player progresses through landmark upgrades.
