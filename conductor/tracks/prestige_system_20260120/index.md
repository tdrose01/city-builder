# Track: Event Prestige System

**Created:** 2026-01-20  
**Status:** In Progress  
**Owner:** AI Agent

## Overview
Implement a prestige system for the event progress that allows players to reset their milestone progress after completing all milestones, earning prestige levels and enhanced rewards on subsequent runs.

## Goals
- Add prestige levels that track how many times player has completed all milestones
- Reset event progress and milestone claims when player prestiges
- Scale up rewards based on prestige level (e.g., 1.5x multiplier per prestige)
- Provide clear UI showing prestige level and benefits
- Make prestiging feel rewarding and worthwhile

## Success Criteria
- Players can prestige after completing all milestones (120+ event points)
- Prestige level is tracked and displayed prominently
- Milestone rewards scale with prestige level
- Event progress resets to 0 after prestige
- Milestone claims reset after prestige
- Clear "Prestige" button appears when eligible
- Prestige confirmation dialog explains benefits
