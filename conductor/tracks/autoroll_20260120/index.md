# Track: Autoroll Feature

**Created:** 2026-01-20  
**Status:** In Progress  
**Owner:** AI Agent

## Overview
Add an autoroll button that allows players to automatically roll dice continuously until they run out of dice or manually stop the autoroll. This feature enhances the user experience by reducing repetitive clicking for players who want to progress quickly through multiple rolls.

## Goals
- Implement a toggle button for autoroll functionality
- Ensure autoroll respects game state (dice availability, movement completion)
- Provide clear visual feedback for autoroll state (active/inactive)
- Allow players to stop autoroll at any time
- Maintain smooth animations and game feel during autoroll

## Success Criteria
- Players can enable/disable autoroll with a single click
- Autoroll automatically stops when dice run out
- All game animations and effects still play during autoroll
- Autoroll state is clearly indicated in the UI
- Players can manually stop autoroll at any time
